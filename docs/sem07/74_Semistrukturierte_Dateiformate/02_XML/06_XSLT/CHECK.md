# Checkliste: XSLT

Bewertungsvorschlag und Einordnung: [Gesamtaufgabe](../../TASK.md#bewertungsvorschlag).

## Grundaufgabe

- [ ] Aus XML gefilterte und numerisch sortierte HTML-Tabelle mit korrekter Ausgabe erzeugt.
- [ ] Sonderzeichen, Leerkatalog, sichere Textdarstellung und Sortierexperiment geprüft.
- [ ] Tests und Kontrollfragen nachvollziehbar dokumentiert.

## Optionale Vertiefung

- [ ] Gruppierte, parametrisierte Ausgabe mit korrekten Gruppen-/Gesamtwerten umgesetzt.
