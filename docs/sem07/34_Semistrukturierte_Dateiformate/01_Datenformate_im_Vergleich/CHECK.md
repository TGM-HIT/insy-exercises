# Checkliste: Datenformate im Vergleich

Bewertungsvorschlag und Einordnung: [Gesamtaufgabe](../TASK.md#bewertungsvorschlag).

## Grundaufgabe

- [ ] Vergleichstabelle mit konkreten Datenstellen erstellt.
- [ ] CSV-Sonderfälle und Kontrollwerte geprüft; Formatentscheidung begründet.
- [ ] Tests und Kontrollfragen nachvollziehbar dokumentiert.

## Optionale Vertiefung

- [ ] Verlustfreien Rundweg und seine Grenzen erklärt.
