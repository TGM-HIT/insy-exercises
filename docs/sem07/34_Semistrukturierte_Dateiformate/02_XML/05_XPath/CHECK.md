# Checkliste: XPath

Bewertungsvorschlag und Einordnung: [Gesamtaufgabe](../../TASK.md#bewertungsvorschlag).

## Grundaufgabe

- [ ] Sechs eigene Ausdrücke mit richtigen Werten und erklärter Semantik formuliert.
- [ ] Leerkatalog, Maximum-Gleichstand und Namespace-Lernversuch geprüft.
- [ ] Tests und Kontrollfragen nachvollziehbar dokumentiert.

## Optionale Vertiefung

- [ ] Namespace-Abfragen sowie eine XPath-3.1-Kategorienmap umgesetzt.
