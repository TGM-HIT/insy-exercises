# Checkliste: DTD und Validierung

Bewertungsvorschlag und Einordnung: [Gesamtaufgabe](../../TASK.md#bewertungsvorschlag).

## Grundaufgabe

- [ ] Eigene DTD entspricht dem Vertrag und akzeptiert Normal- sowie Leerkatalog.
- [ ] Struktur-, ID- und Preis-Grenzfälle samt Lernversuch erklärt.
- [ ] Tests und Kontrollfragen nachvollziehbar dokumentiert.

## Optionale Vertiefung

- [ ] Grenzen gegenüber typisierten Schemas oder Anwendungsprüfung eingeordnet.
