# Checkliste: DOM

Bewertungsvorschlag und Einordnung: [Gesamtaufgabe](../../TASK.md#bewertungsvorschlag).

## Grundaufgabe

- [ ] Drei gezielte Änderungen ohne Verlust übriger Daten umgesetzt.
- [ ] Erneutes Parsen/Validieren, Wiederholung und Textknotenversuch geprüft.
- [ ] Tests und Kontrollfragen nachvollziehbar dokumentiert.

## Optionale Vertiefung

- [ ] Namespace-Variante einschließlich neuem Element korrekt bearbeitet.
